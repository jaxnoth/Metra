The idea

Different kinds of work live in different places. Metra remembers which is which, so the assistant starts in the correct one.

Who it is for

Pick a role to see a concrete example. The idea is the same in each case: keep related work together, then ask from that place.

Teacher

Keep lessons, quizzes, handouts, and classroom projects separated. Ask for a review quiz and Metra directs the helper to the correct materials.

See an example
  1. You ask: “Make a ten-question review quiz for next week’s lesson.”
  2. Metra directs: the matching classroom project with those lesson notes.
  3. You get: a quiz draft kept with that class work - not mixed into another folder.

Organizer

Keep event plans, schedules, printables, and notes together so preparation stays in one lane.

See an example
  1. You ask: “Update the word search for Friday’s get-together.”
  2. Metra directs: the event or trivia project that owns those printables.
  3. You get: a fresh puzzle and answer key in the right output folder.

Technical team

Route tickets and requests to the correct system and keep prior decisions findable so the same problem is not solved from scratch every time.

See an example
  1. You ask: “This disk alert looks familiar - what did we do last time?”
  2. Metra directs: the monitoring or ticket project that owns that work.
  3. You get: the relevant notes and next steps without digging across unrelated folders.

How do I use it?

Metra has two parts: a home folder on your computer, and guidance that shows up when you chat with an assistant such as Cursor.

  1. Install Metra (button above) so your projects have a known front door.
  2. Open that Metra folder in Cursor (or a similar assistant).
  3. Ask in plain language. Metra helps the assistant start in the right project with the right materials, instead of guessing.

Downloading and installing Metra does not open a chat window by itself. The conversation happens in Cursor, using the home base Metra set up.

Get started on Windows

  1. Download MetraSetup.exe
  2. Run the installer. If Windows warns about an unknown publisher, choose More info, then Run anyway.
  3. Leave Run Metra setup now checked, then finish.

Metra installs under your Documents folder by default (a place you already know). You do not need Git for this path.

Two words, once

Home folder
Where Metra lives on your PC after install - usually Documents\Metra. Think of it as the front door, not a mysterious “base folder.”
PowerShell
A built-in Windows tool that can run Metra behind the scenes. The installer and Start Menu shortcut handle that for you. Technical users who prefer the command line can open the GitHub page below.
