Metra keeps projects, notes, and coding tools pointed at the same folder so you spend less time hunting and more time finishing.

Download for Windows

What it helps with

When work lives in many folders, people and AI tools often open the wrong one. Metra is a small home base that remembers which folder owns which kind of ask, and hands you a short map of what matters next.

  • Start from one known place on your computer
  • Point helpers at the project that actually owns the task
  • Keep useful decisions findable later - without rewriting history by accident

Get started on Windows

  1. Download MetraSetup.exe
  2. Run the installer. If Windows warns about an unknown publisher, choose More info, then Run anyway.
  3. Leave Run Metra setup now checked, then finish.

Metra installs under your Documents folder by default (a place you already know). You do not need Git, and you do not need to learn command-line tools for this path.

Two words, once

Home folder
Where Metra lives on your PC after install - usually Documents\Metra. Think of it as the front door, not a mysterious “base folder.”
PowerShell
A built-in Windows tool that can run Metra behind the scenes. The installer and Start Menu shortcut handle that for you. Technical users who prefer the command line can open the GitHub page below.
